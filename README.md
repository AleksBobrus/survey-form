# 📋 Survey Form

Адаптивная форма обратной связи, свёрстанная по макету freeCodeCamp.

🔗 **Демо:** [Survey Form](https://aleksbobrus.github.io/survey-form/)

## 🛠️ Стек
- HTML5 (семантическая вёрстка)
- CSS3 (Flexbox, Grid, медиазапросы)
- Адаптивный дизайн

## ✨ Особенности
- Кроссбраузерная и адаптивная вёрстка (корректно отображается на мобильных устройствах)
- Валидация полей формы средствами HTML
- Чистый, читаемый код
